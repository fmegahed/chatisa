# ChatISA v6.2.0 Release Notes

**Release Date:** July 29, 2026

---

## Overview

One week of production use showed Job Scout's main weakness was its
source, not its matching: JSearch scrapes Google for Jobs, so apply links
routinely landed on LinkedIn, ZipRecruiter, or Indeed, and staffing-agency
ads crowded out real employer postings. This release rebuilds the feed on
**Active Jobs DB**, which indexes 54 applicant-tracking platforms
(Workday, Greenhouse, Taleo, Lever, and the rest) and about 200,000
employer career sites directly. Every apply link on the board now goes to
the employer's own application page. USAJobs stays for the federal track;
it always was direct. (ADR-027.)

## Tailored to ISA students

The searches themselves are now strategic rather than broad:

- Full-time queries are filtered at the source to the 0-2 and 2-5 years
  experience bands, so senior roles are never fetched at all; the tagging
  pass still judges the borderline ads that overstate experience.
- Internship queries use the source's own INTERN classification plus
  widened title clusters, and get a larger share of the weekly budget.
- People-management titles (manager, lead, supervisor) no longer pass the
  relevance gate; leadership development programs for new grads still do.
- Source-flagged duplicates and clearly senior postings are dropped
  before any model spend.

## A clean break from the old feed

Scout postings now live in their own database file (`scout.db`). The
aggregator-era postings remain preserved in the main database but are no
longer read or served, so old and new results never mix. On the first
boot after deploying this release the board starts empty and the
scheduler's boot check runs a harvest immediately; the feed refills
within the hour without operator action.

## Operational notes

- The new source meters returned jobs per month (5,000 on the current
  plan; 2,500 requests). One weekly harvest is budgeted at ~950 jobs and
  a unit test pins the matrix to that budget. The whole run is now 6
  requests to Active Jobs DB plus 8 to USAJobs, down from ~190.
- Same `RAPIDAPI_KEY`; no environment changes.
- 832 unit tests (the new source normalizes a real captured payload, with
  an assertion that no apply URL is an aggregator domain), 17/17 e2e,
  bundle self-test passed.
