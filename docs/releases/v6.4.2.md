# ChatISA v6.4.2 Release Notes

**Release Date:** August 23, 2026

---

## Overview

Two small Portfolio Builder fixes found while filming the module's
executive video the same day v6.4.1 shipped. No new environment variables
are required, no migrations, no other module touched.

## Fixes

- **The preview no longer shows a broken image where the photo goes.** The
  published page loads the photo from `assets/photo.jpg`, a file that exists
  only after the push, so the in-app preview rendered a missing-image icon
  next to the student's name. The preview now substitutes the copy of the
  photo the browser already holds. The published page is unchanged.
- **`CHATISA_MOCK_GITHUB_LOGIN`** (optional, test and demo servers only)
  overrides the login name the mock GitHub connect reports, default
  `mockstudent`. Production ignores it; the mock path only runs under
  `CHATISA_MOCK_GITHUB=1`.

## Operator notes

- Copy `web/deploy/chatisa-app.zip` to the server as usual. The bundle for
  this release includes v6.4.1's fixes if 6.4.1 was not yet deployed.

## Test and gate results

- Typecheck and lint clean; the portfolio route, push engine, and work in
  progress unit suites pass (37 tests). The preview fix is exercised on
  camera in `videos/chatisa/portfolio/` (the photo renders in the preview
  pane at the edit step).
