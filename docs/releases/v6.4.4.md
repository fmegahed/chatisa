# ChatISA v6.4.4 Release Notes

**Release Date:** August 23, 2026

---

## Overview

One Portfolio Builder fix, found reviewing the module's executive video:
course lines on the career page could read "ISA 444: Business :" with the
title missing. No new environment variables, no migrations, no other module
touched.

## Fix

- **Coursework lines show the course title.** Models sometimes put the
  title into the course code field ("ISA 444: Business", clipped), which the
  page then could not match to the catalog, so the title came out blank.
  Three changes: the model is told to return only the code; the server
  normalizes each returned code against the courses the student actually
  listed and drops anything else (no invented courses); and the page prints
  the catalog title itself, so a line reads "ISA 444 Business Forecasting:
  I used forecasting concepts from this course to...". Sites already
  published are unaffected until republished.

## Operator notes

- Copy `web/deploy/chatisa-app.zip` to the server as usual. This bundle
  supersedes the v6.4.1 through v6.4.3 bundles built earlier today.

## Test and gate results

- Typecheck and lint clean; portfolio route, renderer, and content suites
  pass (29 tests). The mock model now deliberately returns a title-stuffed
  code and an unlisted course so the normalizer is exercised on every run.
  The fix is visible in the Portfolio Builder video (cut 3), where the
  coursework section shows full titles.
