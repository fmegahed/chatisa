# ChatISA v6.4.3 Release Notes

**Release Date:** August 23, 2026

---

## Overview

Two more Portfolio Builder fixes from the same day's filming, both about
what a student sees before publishing. No new environment variables, no
migrations, no other module touched.

## Fixes

- **The showcase preview shows the student's figures.** The published page
  loads figures from `figures/<name>`, files that exist only after the push,
  so the edit-step preview showed a broken image where an uploaded chart
  belonged (the same cause as v6.4.2's photo fix, now handled for figures
  too). The preview inlines the uploaded image bytes; the published page is
  unchanged.
- **The file meter explains the site's own files.** Before the first upload
  the meter read "3 of 60 files", which looked like a mistake. It now reads
  "0 of your files, plus 3 the site needs (its page, a README, settings):
  3 of 60 files". The limit is unchanged; the three files were always
  counted.

## Operator notes

- Copy `web/deploy/chatisa-app.zip` to the server as usual. This bundle
  supersedes the v6.4.1 and v6.4.2 bundles built earlier today.

## Test and gate results

- Typecheck and lint clean; the portfolio files and route suites pass (18
  tests). Both fixes are exercised on camera in the Portfolio Builder
  video (cut 2): the ROC figure renders on the showcase page, and the
  project step shows the new meter copy.
