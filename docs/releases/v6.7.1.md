# ChatISA v6.7.1 Release Notes

**Release Date:** September 24, 2026

---

## Overview

A fix to the catalog refresh Action, found on its first run. Nothing
students use changes, so there is no new server bundle: the v6.7.0 bundle
stays current (its footer keeps reading v6.7.0).

## Fix

- **The catalog collector retries a dropped connection.** The first run of
  the catalog refresh Action stopped when the Bulletin's server closed the
  connection partway through a page ("fetch failed: other side closed"),
  before any model was called, so it cost nothing. Only HTTP error codes
  were retried. A dropped connection, or a page that breaks off while it is
  being read, is now retried the same way, up to four attempts with a
  growing pause.

## Operator notes

- No deploy needed. Rerun "Catalog refresh" from the Actions tab.

## Test and gate results

- Unit: the catalog suites pass 90/90, including four new failing-first
  tests for the retry (dropped connection, body cut off mid-read, giving up
  after four attempts, HTTP errors still retried). Typecheck and lint clean.
