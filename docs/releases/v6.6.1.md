# ChatISA v6.6.1 Release Notes

**Release Date:** September 23, 2026

---

## Overview

Three small Portfolio Builder fixes from the v6.6.0 review, shipped the
same day at the professor's request. Drafts being stored per browser
rather than per account was also noted in that review and is by design:
people sharing a computer are expected to use separate logins.

## Fixes

- **No empty course labels on published pages.** A Miami course whose
  code was cleared in the review editor is now left off the page, the way
  a blanked outside course already was, and a course with no reason
  written yet shows as its label alone rather than "ISA 444:" followed by
  nothing.
- **Typed course text is fenced in the prompt.** A guest's outside courses
  and a showcase's "course at another school" now reach the model inside
  the same fence as every other piece of student-written text, so a
  course name is always read as data and cannot close its own fence. This
  could only ever have affected the author's own page.
- **Guests keep a course they already chose.** A guest resuming a
  showcase saved before v6.6.0 (when the Miami course list was the only
  option) now keeps that course as their "course at another school"
  instead of losing it.
