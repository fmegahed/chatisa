# ChatISA v6.1.0 Release Notes

**Release Date:** July 29, 2026

---

## Overview

Version 6.1.0 adds **Job Scout**, a ninth module that leads the job-search
group: a board of analytics, information systems, and security jobs
refreshed every Sunday and matched against the ISA courses a student has
actually taken. It closes the loop the job modules always implied: find a
job, draft the application, practice the interview, and build the portfolio
that backs it all up, without describing the same job or re-uploading the
same resume twice.

What a student sees:

- **A pre-populated weekly board.** No searching. Postings arrive from
  JSearch and USAJobs every Sunday at 2 AM Eastern, covering entry-level
  roles across Ohio and regional hubs, remote and national markets,
  internships and co-ops, and a federal track. Every posting links to the
  employer's own application page.
- **Matching that speaks their language.** Each posting shows a coverage
  fraction ("2/3 required skills covered"), a plain-words band (Strong /
  Good / Stretch), what they bring, and what the gaps are, with the course
  each skill came from. Matching runs in the browser: the server never
  learns who matches what.
- **A profile built from the curriculum.** Students check off ISA courses
  (popular ones first) and watch a live skills panel fill in, compare
  themselves against the week's most-wanted skills, adjust any level they
  disagree with, and optionally add skills from a resume that then stays on
  their device for one-click reuse in JobApp Drafter and Interview Mentor.
- **Projects with a home.** The primary path polishes work they already
  did: upload real coursework files and get back a clean repo layout, a
  grounded README with a suggested-improvements section, warnings about
  files that should not be published, and honest resume bullets, with
  their code shipped verbatim. A generate-from-scratch scaffold remains
  for students starting fresh. Both are kept as artifacts, re-downloadable
  as zips, with GitHub CLI instructions; a polished project's skills count
  in the profile immediately.

## Privacy

The local-first contract extends to careers (ADR-025): courses taken,
confirmed skills, level overrides, saved jobs, project artifacts, and the
resume all live only in the student's browser (localStorage and IndexedDB).
The server stores public employer postings and content-free usage events,
nothing student-keyed. A server record appears only when the student
chooses to draft documents in JobApp Drafter, exactly as pasting a posting
did before.

## The pipeline

- In-process scheduler (the app's first background job), Sunday 2 AM
  America/New_York, DST-safe, crash-safe (persisted run history, catch-up
  at boot), with a manual admin trigger and freshness in the deep health
  check.
- ~190 requests per weekly run against JSearch (10,000/month plan) and
  USAJobs; per-posting tagging by `gemini-3.6-flash` against a closed
  ~104-skill taxonomy (skill ids enforced deterministically after
  generation), with required/preferred importance, a visa-sponsorship
  stance taken only from the posting's own words, a 30-day age limit, and
  a hard per-run cost cap recorded in dollars.
- The course-to-skill mapping is data under test: leveled links
  (anchor/applied/exposure) over the live bulletin catalog with evidence
  phrases that ground resume bullets, plus a two-model regeneration script
  for curriculum changes.

## Quality

- 819 unit tests (84 new for Job Scout: DST-boundary scheduler pins,
  hand-computed matching examples, harvest failure semantics incl. the
  quota stop, store migrations) and a 17-scenario e2e suite across desktop
  and 320px mobile, axe WCAG A/AA clean.
- New environment: `RAPIDAPI_KEY`, `USAJOBS_API_KEY`, `USAJOBS_EMAIL`
  (feed sources; absent keys degrade honestly), `CHATISA_SCOUT_ADMINS`,
  `CHATISA_SCOUT_MAX_RUN_USD`. See `chatisa.env.example`.
- Decision records: ADR-025 (cached public postings, in-process scheduler,
  local-first career data), ADR-026 (flash-tier tagging with a cost cap).

## Also in this release

- JobApp Drafter and Interview Mentor accept handoffs: a Job Scout posting
  prefills the job, finished documents link into a matching interview
  (finally using the `interviews.applicationId` column reserved in 6.0.0),
  and both tools offer the resume saved on the device.
- Professional skills (communication, teamwork) no longer count as
  required in matching or appear as gaps.
- Aggregator-stuffed titles cleaned at harvest; login/guest logo aspect
  ratio warning fixed.
