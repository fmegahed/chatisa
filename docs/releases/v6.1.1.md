# ChatISA v6.1.1 Release Notes

**Release Date:** July 29, 2026

---

## Overview

A patch release that makes coursework files first-class uploads. ISA
students hand in `.R`, `.Rmd`, `.qmd`, `.py`, and `.ipynb` files; before
this release Ask Anything refused most of them outright (Windows browsers
report no MIME type for code files), and the My Projects polish flow
could not see inside a notebook because the per-file text cap usually
landed inside the first base64 plot blob.

## Ask Anything

- The attachment picker accepts `.py`, `.R`, `.Rmd`, `.qmd`, `.ipynb`,
  and `.html` alongside everything it took before. Code files ride as
  text no matter what MIME type the browser reports.
- Jupyter notebooks are converted in the browser: markdown and code cells
  with capped text outputs become the text the model reads, and up to
  four plot outputs are attached as real images, so a "review my
  notebook" question can be answered about the charts too. Neither
  provider stores the notebook; the conversion is the same client-side
  path Word and PowerPoint already use.

## My Projects (Job Scout)

- Polish extracts notebook cells before the text cap and allows
  notebooks up to 5 MB raw (the bulk is plot data the extraction strips),
  so the model organizes what the student actually wrote. The downloaded
  zip still ships the original files byte-for-byte.
- The organizing prompt now knows R and Python course ecosystems:
  rendered HTML next to its `.Rmd`/`.qmd` source, `_files/` folders,
  `.Rproj.user`, `.ipynb_checkpoints`, `__pycache__`, `.venv`, and
  `renv/library` are steered into exclude/.gitignore; lockfiles stay.
- Honest notices replace two silent behaviors: files too large to read
  are called out (they are placed in the layout but not read), and
  choosing more than 15 files says so.

## Fixes

- A polish request failed entirely when the model echoed a filename with
  a space (the common "Final Project.ipynb") into a repo path; such
  paths are now hyphenated deterministically instead.
- Re-downloading a polished project writes the full original text files
  rather than the truncated copies that were sent to the model.

## Quality

- 829 unit tests (notebook converter, MIME-blank classification pins,
  space-path guard) and extended e2e scenarios in both modules, desktop
  and 320px mobile. No storage or API schema changes; existing chats,
  profiles, and artifacts are untouched.
